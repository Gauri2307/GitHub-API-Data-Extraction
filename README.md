# GitHub API Data Extraction and Analysis

## Project Overview

This project demonstrates how to extract, process, and analyze real-world GitHub repository data using Python and the GitHub REST API.

## Technologies Used

- Python
- REST API
- Requests
- Pandas
- Google Colab
- CSV and Microsoft Excel

## Project Objectives

- Extract data from public GitHub repositories.
- Retrieve repository names, stars, forks, programming languages, and open issue counts.
- Convert JSON responses into structured datasets.
- Analyze repository statistics using Pandas.
- Export the extracted data into CSV and Excel files.

## Repositories Analyzed

1. pandas-dev/pandas
2. numpy/numpy
3. psf/requests
4. pallets/flask
5. django/django

## Project Workflow

1. Identified GitHub REST API endpoints.
2. Sent HTTP GET requests using Python.
3. Retrieved and processed JSON responses.
4. Applied request headers, timeouts, and error handling.
5. Converted extracted records into a Pandas DataFrame.
6. Analyzed repository statistics.
7. Exported the data into CSV and Excel formats.

## Project Files

- `Untitled6.ipynb` — Python notebook containing the extraction and analysis code.
- `github_repositories.csv` — Extracted repository dataset.
- `github_repositories.xlsx` — Excel version of the dataset.

## Key Learning Outcomes
